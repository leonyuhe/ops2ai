> 前提假设：在职学习，每周可投入 6-8 小时，有一台可跑实验的机器（或云 GPU 预算）。

## 阶段一：破冰（第 1-4 周）

目标：会用、有手感、建立词汇表。

- 注册并使用主流大模型 API，写出一个能跑的小工具（如日志摘要器）
- 理解 token、prompt、temperature、上下文窗口是什么
- 把 AI 认知补课模块的文章读完

验收：能向同事解释"大模型是怎么逐字生成回答的"。

## 阶段二：工程上手（第 5-10 周）

目标：Python 工程能力 + GPU 服务器实操。

- Python：虚拟环境、异步 IO、并发、打包——对照你的 Shell 经验学
- 在一台 GPU 机器上完成：驱动/CUDA 安装、PyTorch 跑通、显存监控
- 用 vLLM 在单卡上部署一个开源模型并提供 OpenAI 兼容 API

验收：独立完成"申请云 GPU → 部署 Qwen 小模型 → 压测出 TTFT/TPOT"全流程。

## 阶段三：Infra 核心（第 11-18 周）

目标：建立分布式训练与推理优化的知识体系。

- 训练侧：显存账本（权重/梯度/优化器状态/激活）、DDP→FSDP→ZeRO 的演进逻辑、张量/流水并行直觉
- 推理侧：KV Cache、PagedAttention、Continuous Batching、量化（INT8/INT4/FP8）、PD 分离
- 每周一篇笔记发到本站仓库——这也是你的作品集

验收：能画出"70B 模型训练和服务分别需要几张卡"的完整推导。

## 阶段四：生产实战（第 19-24 周）

目标：把运维经验变现为 AI 生产能力。

- K8s 上部署推理服务：GPU 调度、HPA、滚动升级
- 搭建 LLM 可观测性：延迟分位、token 成本、评测回归门禁
- 做一次完整的容量规划演练：给定 QPS 和 SLO，算出需要几张什么卡

验收：向朋友完整讲解你搭的推理平台架构图。

## 阶段五：求职冲刺（第 25-26 周）

- 整理个人项目页（你的 GitHub 仓库就是简历附件）
- 刷面经题库，按"理论问答 + 项目深挖"两类准备
- 投递"平台/Infra/推理"关键词岗位

## 坚持的三个原则

1. **每周必须动手**：只看不动手的学习路线都是安慰剂。
2. **公开输出**：笔记发到仓库，既是作品集也是面试谈资。
3. **不要先学数学**：工程岗需要的是直觉和账本，不是证明。遇到具体公式再回头补。
